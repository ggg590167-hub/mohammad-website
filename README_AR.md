# Mohammad Alasad Engineering & Smart Energy Website — Black & Gold Edition

موقع عربي متجاوب (RTL) للتعريف بخدمات م/ محمد الأسد في محافظة إب، الجمهورية اليمنية.

## محتويات المشروع
- `index.html`: الموقع كاملًا، بما فيه CSS وJavaScript المضمّنان.
- `robots.txt`: توجيه عام لزواحف البحث.
- `sitemap.xml`: خريطة أولية للصفحة الرئيسية (حدّث رابط النطاق بعد النشر).
- `assets/`: مساحة للصور الحقيقية والشعار لاحقًا.

## التشغيل على هاتف سامسونج
1. نزّل ملف ZIP واستخرجه باستخدام تطبيق «ملفاتي» أو مدير ملفات موثوق.
2. افتح مجلد المشروع ثم اضغط `index.html`.
3. اختر متصفحًا مثل Chrome أو Samsung Internet.
4. جرّب الحاسبة وأزرار الاتصال وواتساب. قد تتطلب بعض مديري الملفات فتح الملف في المتصفح يدويًا.

## طلب الخدمة
النموذج لا يرسل البيانات إلى خادم ولا يخزنها. إنه ينشئ رسالة ويفتح رابط WhatsApp؛ على المستخدم مراجعة الرسالة وإرسالها بنفسه. الاتصال والبريد ينقلان المستخدم إلى التطبيق المختار.

## النشر
يمكن رفع `index.html` و`robots.txt` و`sitemap.xml` إلى أي استضافة ملفات ثابتة تدعم HTTPS. بعد اختيار نطاق حقيقي، حدّث `sitemap.xml` وبيانات `og:url` إن أضفتها، ثم أضف الموقع إلى Google Search Console. لا يتضمن المشروع إعداد حساب استضافة أو نشرًا تلقائيًا.

## ملاحظات هندسية وسلامة
- حاسبة البطارية أداة تعليمية تقديرية فقط، بافتراض جهد اسمي ثابت وحمل ثابت، ولا تشمل جميع الفواقد أو حدود BMS أو تغير الجهد.
- لا تستخدم النتائج وحدها لاختيار الكابلات أو القواطع أو الألواح أو إعدادات الشحن. راجع بيانات المصنع والمعايير المناسبة والقياسات الميدانية.
- لا توجد مشاريع سابقة أو شهادات أو تقييمات مختلقة.
- لم تُضف صور مشاريع غير حقيقية.
- لا توجد كلمات مرور أو مفاتيح API أو أسرار ضمن الملفات.

## الاختبارات التي أجريت
تحقق الإنشاء البرمجي من وجود الملفات، وإمكانية قراءة ZIP واختبار CRC لجميع عناصره، والتحقق من وجود عناصر HTML أساسية وروابط التواصل، وفحص توازن وسوم HTML الأساسية واستخراج JavaScript للتحقق من تركيبه بواسطة Node.js عند توفره في بيئة الإنشاء.
اختبارات العرض الفعلي على جهاز سامسونج، واختبارات المتصفحات، والنشر العام، وفحص الروابط الخارجية الحية لم تُنفذ في هذه البيئة؛ يجب تنفيذها بعد تنزيل النسخة وقبل اعتمادها رسميًا.
